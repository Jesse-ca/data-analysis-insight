# 使用文档

## 快速开始

### 1. 上传Excel

用户上传Excel文件到skill。

### 2. 自动分析

skill自动执行：
1. 识别数据结构和业务场景（AI自由推断）
2. 推断KPI和公式
3. 选择图表类型
4. 编排分析流程
5. 生成HTML报告

### 3. 获取结果

用户获得完整的HTML分析报告，可直接在浏览器打开。

---

## 执行流程详解

```
用户上传Excel
    ↓
【Step 1】数据接收
    ↓
【Step 2】场景识别（scene-recognizer）
    - 识别数据结构（单表/多表/双表）
    - AI自由推断业务场景
    - 识别字段类型
    - 识别数据规模
    ↓
【Step 3】指标推断（metric-inferencer）
    - AI自由推断KPI列表
    - 推断计算公式
    - 推断分析维度
    ↓
【Step 4】图表选型（chart-selector）
    - 按数据特征选择图表
    - 规则写死，不让AI判断
    ↓
【Step 5】流程编排（flow-orchestrator）
    - 选择PDCA/PDCAWFR/Tool
    ↓
【Step 6】生成提示词
    - 组装完整分析提示词
    ↓
【Step 7】AI执行
    - 按提示词生成HTML
    ↓
【Step 8】输出
    - 用户获得HTML报告
```

---

## 场景识别规则

**不限定具体场景**，AI根据数据特征自由推断。

AI识别时参考以下维度：
- 数据结构：单表/多表/双表
- 字段特征：日期类、数值类、分类类、ID类
- 业务关键词：从字段名推断业务含义
- 行业特征：从指标名称推断行业
- 用户意图：从用户描述推断场景

---

## 图表选型规则

| 数据特征 | 图表类型 | 原因 |
|----------|----------|------|
| 时间序列 ≤5点 | 柱状图 | 数据点少，柱状图清晰 |
| 时间序列 6-12点 | 折线图 | 数据点适中，折线图展示趋势 |
| 时间序列 >12点 | 面积图 | 数据点多，面积图展示趋势 |
| 类别对比 ≤5类 | 柱状图 | 类别少，柱状图对比清晰 |
| 类别对比 >5类 | 横向条形图 | 类别多，横向排列易读 |
| 占比分析 ≤6类 | 饼图 | 类别少，饼图展示占比 |
| 占比分析 >6类 | 环形图 | 类别多，环形图更清晰 |
| 2分类+1数值 | 热力图 | 多维交叉分析 |
| 3维度 | 气泡图 | 展示三维关系 |

## 流程编排规则

| 场景复杂度 | 流程 | 特征 |
|------------|------|------|
| 低 | PDCA | 单表+基础KPI |
| 中 | PDCA | 多表+基础KPI |
| 高 | PDCAWFR | 多表+复杂KPI+预测诊断 |
| 交互 | Tool | 多表关联+公式计算 |

## 用户配置（可选）

### 不需要配置

skill自动工作，上传Excel就能用。

### 可选配置

如果AI推断不准，用户可以提供：

1. **KPI公式**：自定义计算公式
2. **分档规则**：自定义阈值和档位
3. **特殊图表**：自定义图表类型

### 配置文件位置

```
configs/
├── frameworks/     # 提示词框架
└── custom-rules/   # 特殊规则
```

## 输出格式

### HTML报告包含

1. **报头**：标题、描述
2. **KPI卡片**：核心指标数值
3. **图表区**：可视化图表
4. **数据表格**：明细数据
5. **洞察报告**：AI分析洞察
6. **行动建议**：优先级建议
7. **页脚**：下载按钮

### 技术规范

- 单HTML文件 ≤500KB
- 数据本地处理，不连API
- 支持拖拽上传
- 图表可交互（tooltip/animation）

## 常见问题

### Q: 上传Excel后没反应？
A: 检查文件格式是否为.xlsx

### Q: 图表显示不正确？
A: 检查数据格式是否正确，数值字段是否有文字

### Q: KPI计算错误？
A: 可能是字段识别错误，可提供自定义公式

### Q: 如何自定义分析？
A: 在configs/目录下添加配置文件

## 示例

### 示例1：销售分析

**输入**：销售订单Excel
**输出**：
- KPI：销售额、订单数、客单价
- 图表：月度趋势、区域对比、渠道占比
- 洞察：区域表现、渠道效率、增长趋势

### 示例2：进销存分析

**输入**：库存数据Excel
**输出**：
- KPI：库存量、周转率、周转天数
- 图表：库存趋势、产品周转对比
- 洞察：库存结构、周转效率、预警提示

### 示例3：报关比对

**输入**：报关数据+主数据Excel
**输出**：
- KPI：一致率、异常数
- 图表：差异分布、时间趋势
- 洞察：差异分析、预警评估
