# 成功标准

## 核心指标

### 1. 文件输出

| 指标 | 目标 | 说明 |
|------|------|------|
| HTML文件大小 | ≤500KB | 单HTML文件，可直接打开 |
| 数据处理时间 | ≤30s | 从上传到生成HTML |
| 图表渲染成功率 | 100% | 所有图表正常显示 |

### 2. 场景识别

| 指标 | 目标 | 说明 |
|------|------|------|
| 场景识别准确率 | ≥80% | 正确识别业务场景 |
| 字段类型识别准确率 | ≥90% | 正确识别字段类型 |
| 表间关系识别准确率 | ≥70% | 正确识别外键关联 |

### 3. 指标推断

| 指标 | 目标 | 说明 |
|------|------|------|
| KPI推断准确率 | ≥70% | 推断的KPI符合业务需求 |
| 公式正确率 | ≥90% | 计算公式正确 |
| 维度选择准确率 | ≥80% | 选择的维度符合分析需求 |

### 4. 图表选型

| 指标 | 目标 | 说明 |
|------|------|------|
| 图表类型匹配率 | ≥85% | 图表类型适合数据特征 |
| 图表可读性 | ≥80% | 图表清晰易读 |
| 图表交互性 | 100% | tooltip正常工作 |

### 5. 输出质量

| 指标 | 目标 | 说明 |
|------|------|------|
| 洞察数量 | ≥3条 | 每次分析至少3条洞察 |
| 洞察量化率 | ≥80% | 洞察包含具体数字 |
| 建议可执行率 | ≥70% | 建议具体可执行 |

## 验证方法

### 1. 文件输出验证

```bash
# 检查文件大小
ls -lh report.html

# 检查生成时间
time python generate.py
```

### 2. 场景识别验证

```
- 上传已知场景的Excel
- 检查识别结果是否正确
- 记录准确率
```

### 3. 指标推断验证

```
- 对比推断的KPI与预期KPI
- 检查公式是否正确
- 记录准确率
```

### 4. 图表选型验证

```
- 检查图表类型是否适合数据特征
- 检查图表是否清晰易读
- 记录匹配率
```

### 5. 输出质量验证

```
- 检查洞察数量是否≥3条
- 检查洞察是否包含具体数字
- 检查建议是否可执行
```
