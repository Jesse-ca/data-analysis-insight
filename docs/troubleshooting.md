# 故障排除

## 常见问题

### 1. 文件相关

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 无法上传文件 | 文件格式不支持 | 请上传.xlsx或.xls格式文件 |
| 文件为空 | Excel中无数据 | 请检查Excel是否有数据 |
| 文件过大 | 超过10MB | 请压缩数据或分批处理 |
| 编码错误 | 中文乱码 | 请保存为UTF-8编码 |

### 2. 数据相关

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 无法识别场景 | 数据结构不明确 | 请补充说明数据用途 |
| KPI推断错误 | 字段名不规范 | 请修改字段名为明确含义 |
| 公式计算错误 | 字段类型不匹配 | 请确保数值字段为数字格式 |
| 维度选择错误 | 分类字段过多 | 请指定主要分析维度 |

### 3. 图表相关

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 图表显示异常 | 数据点过少 | 请检查数据量是否足够 |
| 图表类型不匹配 | 数据特征识别错误 | 请手动指定图表类型 |
| 图表样式问题 | 样式冲突 | 请刷新页面重试 |

### 4. 输出相关

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| HTML文件过大 | 数据量过大 | 请压缩数据或减少维度 |
| 浏览器打不开 | 浏览器版本过低 | 请升级浏览器或使用Chrome |
| 样式错乱 | 浏览器兼容性 | 请使用Chrome或Firefox |

## 调试建议

### 1. 检查数据格式

```
- 日期字段：确保为日期格式，不是文本
- 数值字段：确保为数字格式，不是文本
- 分类字段：确保值一致，无多余空格
```

### 2. 检查字段命名

```
- 使用明确的字段名（如"销售额"而非"金额1"）
- 避免特殊字符（如/、\、*等）
- 避免过长字段名（建议≤20字符）
```

### 3. 检查数据规模

```
- 建议：100-10000行数据
- 过少：可能无法生成有意义的洞察
- 过多：可能导致处理时间过长
```
