# 图表选型模块

## 职责

根据数据特征，自动选择合适的图表类型。规则写死，不让AI判断。

## 图表选择矩阵

### 时间序列数据

| 数据特征 | 图表类型 | 适用场景 |
|----------|----------|----------|
| ≤5个时间点 | 柱状图 | 月度达成、月度客户数变化 |
| 6-12个时间点 | 折线图 | 季度趋势、年度趋势 |
| >12个时间点 | 面积图 | 长期趋势、历史对比 |

### 类别对比数据

| 数据特征 | 图表类型 | 适用场景 |
|----------|----------|----------|
| ≤5个类别 | 柱状图 | 区域对比、渠道对比 |
| >5个类别 | 横向条形图 | 品类排名、销售员TOP |
| 名字较长 | 横向条形图 | 产品名称、客户名称 |

### 占比分析数据

| 数据特征 | 图表类型 | 适用场景 |
|----------|----------|----------|
| ≤6个类别 | 饼图 | 渠道占比、品类占比 |
| >6个类别 | 环形图 | 客户分层、区域分布 |
| 多层级结构 | 旭日图 | 组织架构、产品分类 |

### 关联分析数据

| 数据特征 | 图表类型 | 适用场景 |
|----------|----------|----------|
| 2分类+1数值 | 热力图 | 区域×渠道、品类×月份 |
| 3维度 | 气泡图 | 规模×效率×增长率 |
| 流程数据 | 漏斗图 | 转化率、流失分析 |

### 排名数据

| 数据特征 | 图表类型 | 适用场景 |
|----------|----------|----------|
| TOP N | 条形图 | 销售排名、绩效排名 |
| 对比排名 | 双向条形图 | 同比对比、目标对比 |

### 分布数据

| 数据特征 | 图表类型 | 适用场景 |
|----------|----------|----------|
| 连续数值 | 直方图 | 价格分布、年龄分布 |
| 离散数值 | 柱状图 | 评分分布、等级分布 |

## 选型流程

```
1. 识别数据特征
   - 是时间序列吗？→ 统计时间点数量
   - 是类别对比吗？→ 统计类别数量
   - 是占比分析吗？→ 检查是否需要占比
   - 是关联分析吗？→ 检查维度数量

2. 匹配图表类型
   - 按上表规则匹配

3. 生成图表配置
   - 标题、坐标轴、数据系列

4. 输出选型结果
```

## 多列维度处理规则（写死）

**场景**：某些"维度"不是单列，而是多列。典型情况：产品型号数据分布在N个独立列中（如HL-L1228、DCP-L1638W等），每列的值是该型号的数量/金额。

**识别方法**：
- 字段名像型号代码（字母+数字组合，如HL-L1228、DCP-L1638W）
- 多个字段结构相同（都是数值列，值域相近）
- 字段数量≥3个且命名模式一致

**处理规则**：

| 图表类型 | 多列维度在X轴 | 多列维度在Y轴 |
|----------|--------------|--------------|
| **热力图** | X=列名（型号），Y=其他维度，值=该列求和 | Y=列名（型号），X=其他维度，值=该列求和 |
| **柱状图** | 按列聚合求和，X=列名，Y=总值 | 按列聚合求和，Y=列名，X=总值 |
| **横向条形图** | 同柱状图，但翻转轴 | 同柱状图，但翻转轴 |
| **饼图/环形图** | 每列求和作为一项，列名作为标签 | 不适用（Y轴是维度不是度量） |
| **折线图** | 不适用（多列不是时间序列） | 不适用 |
| **气泡图** | 不适用 | 不适用 |

**聚合逻辑**：
```
for each 其他维度值 d:
    for each 多列 productCol:
        value = SUM(row[productCol] WHERE 维度=d)
        → 输出 [列名, d, value]
```

**禁止事项**：
- ❌ 把多列当作单一维度值处理
- ❌ 对多列做跨列聚合后再按其他维度分组（会丢失型号信息）
- ❌ 在饼图中使用多列作为维度（不支持）

## 特殊图表（用户扩展）

用户可以在配置文件中定义特殊图表：

```json
{
  "customCharts": [
    {
      "name": "四象限图",
      "type": "quadrant",
      "xAxis": "赔付率",
      "yAxis": "费用率",
      "bubble": "保费规模",
      "thresholds": {"x": 50, "y": 30}
    }
  ]
}
```

## 错误处理

- 数据不足 → 显示"数据不足，无法生成图表"
- 图表类型不匹配 → 使用默认图表（柱状图）
- 配置错误 → 使用默认配置
