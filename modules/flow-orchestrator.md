# 流程编排模块

## 执行约束（写死）

1. 只输出规则指定的JSON格式
2. 禁止添加解释性描述
3. 禁止修改输出格式
4. 禁止跳过任何编排步骤
5. 缺任何一项 → 输出错误提示

## 职责

根据场景复杂度，选择合适的分析流程。

## 流程类型

### 1. PDCA（基础分析）

**适用场景**：
- 数据结构简单（单表或简单多表）
- 用户只要基础分析
- 没有复杂计算需求

**流程**：
```
P（Plan）：需求拆解
D（Do）：数据执行
C（Check）：逻辑自检
A（Action）：行动建议
```

### 2. PDCAWFR（深度分析）

**适用场景**：
- 数据结构复杂（多表关联）
- 用户要求深度分析
- 需要预测、诊断、模拟

**输出载体（写死）**：静态HTML报告（数据已嵌入，打开即看）

**流程**：
```
P（Plan）：需求拆解
D（Do）：数据执行
C（Check）：逻辑自检
W（What-if）：情景模拟
F（Forecast）：趋势预测
R（Root Cause）：根因诊断
A（Action）：行动建议
```

### 3. Tool（计算工具）

**适用场景**：
- 用户需要交互式计算工具
- 多表关联、复杂公式
- 需要实时计算

**流程**：
```
1. 数据上传与解析
2. 配置计算规则
3. 生成交互界面
4. 实时计算与展示
5. 导出结果
```

**⚠️ 重要限制（写死）**：
- Tool模式禁止WFR分析（离线工具无法调用AI）
- 只使用8类固定规则驱动的洞察

## 编排逻辑

**默认规则（写死）**：
- 默认走PDCAWFR
- 只有用户明确说"生成看板工具"或"做HTML工具"，才走Tool模式

**看板 vs 工具（写死）**：

| 概念 | 数据来源 | 交互性 |
|------|---------|--------|
| **看板** | 数据已嵌入HTML | 无交互 |
| **工具** | 用户上传Excel | 实时计算 |

```
用户说法 → 流程
"分析数据"、"生成报告"、"做个看板"、"分析一下" → PDCAWFR
"生成看板工具"、"做HTML工具"、"做个交互式工具" → Tool
```

## WFR智能判断规则（写死）

```
F：有≥2期数据 + 有时间维度 → 执行F
R：C阶段有异常 / 维度≥2 → 执行R（输出5-8条根因）
W：C阶段有异常 + 维度≥3 → 执行W（针对KPI，不是异常值）
```

## R阶段方法选择

| 方法 | 适用场景 |
|------|----------|
| 5 Whys | 单一问题根因 |
| 鱼骨图 | 多因素分析 |
| 价值树 | 指标拆解 |
| 下钻归因 | 维度交叉分析 |
| 帕累托分析 | 关键少数 |
| 时间序列归因 | 趋势异常 |
| 组合维度归因 | 多维交叉 |

**R输出要求（写死）**：
- 每次输出5-8条根因
- 每条包含：方法选择依据、判断标准、量化数据、反例检验、边界条件、置信度

## F阶段方法选择

| 方法 | 适用场景 |
|------|----------|
| 移动平均 | 数据波动小 |
| 加权移动平均 | 近期数据重要 |
| 指数平滑 | 有趋势 |
| 线性回归 | 明显线性趋势 |
| 简单同比/环比 | 有同期数据 |
| 季节性分解 | 有年度周期 |

**F输出要求（写死）**：
- 预测值 + 置信区间
- 方法选择理由
- 置信度（高/中/低）
- 数据局限性说明

## W阶段计算逻辑

```
1. 按[分组维度]分组，计算各组基础乘数 = 该组指标 ÷ 整体平均
2. 加权后系数 = 基础乘数 × (权重 ÷ 平均权重)
3. 模拟各组 = 基准各组 × (1 + 自变量) × 加权后系数
4. 模拟总额 = 各组模拟加总
```

**W输出要求（写死）**：
- 滑块实时联动
- 新区块标题："🎯 情景模拟器"

## C阶段自检逻辑（写死）

```
总量校验：各分类加总 = KPI总计
公式校验：分子分母、单位、小数位数
极端值校验：异常极值检查
```

## 复杂度判断规则

| 条件 | 复杂度 | 流程 |
|------|--------|------|
| 单表 + 字段≤10 | 低 | PDCA |
| 多表 + 字段≤20 | 中 | PDCA |
| 多表 + 字段>20 | 高 | PDCAWFR |
| 有公式计算 | 高 | PDCAWFR 或 Tool |
| 需要交互 | 高 | Tool |

## 错误处理

- 流程类型不明确 → 使用PDCA
- 阶段执行失败 → 跳过该阶段，继续后续
- 用户配置冲突 → 以用户配置为准
