# HTML组装模块

## 执行约束（写死）

1. 只输出规则指定的HTML结构
2. 禁止添加解释性描述
3. 禁止修改输出格式
4. 禁止跳过任何组装步骤
5. 缺任何一项 → 输出错误提示

## 职责

将分析结果组装成完整的HTML报告。

## 输出格式

单HTML文件（PC端为主），包含：
1. 报头（标题 + 数据概览）
2. 核心结论速览（3-5条）
3. KPI卡片（6个）
4. 图表区（单维度 + 组合维度）
5. 洞察报告（8类，≥7条）
6. 根因诊断（R阶段，5-8条）
7. 趋势预测（F阶段）
8. 情景模拟（W阶段）
9. 行动建议
10. 数据自检（页脚）

## 字段识别（写死）

**识别优先级**：
1. 精确匹配标准字段名
2. 模糊匹配别名列表
3. 按字段内容推断（数值+金额/数量/率→度量，文本+类型/渠道/区域→维度）
4. 按位置兜底（最后一列=度量，前三列=维度）

**内置别名表**：

| 别名 | 标准字段名 |
|------|-----------|
| 零售全产品总金额 / 总金额 / 总销售 / 销售总额 | total |
| 属性 / 渠道 / 渠道名称 / 销售渠道 | channel |
| 办事处 / 分公司 / 区域 | office |
| 地区 / 区域名称 / 省份 | region |
| 公司名称 / 公司 | company |
| 店铺名称 / 店铺 / 门店 | store |
| 日期 / 时间 / 月份 / 年月 | date |

## 洞察报告（写死）

**8类通用方法**：

| 标签 | 方法 | 公式 |
|------|------|------|
| A. 极值 | 找最高/最低 | max/min(groupBy(field).指标) |
| B. 集中度 | 帕累托 | top1 / total |
| C. 趋势 | 环比 | (cur - prev) / prev |
| D. 异常 | 超阈值 | 指标 > threshold |
| E. 关联 | 多维交叉 | groupBy([d1, d2]) |
| F. 偏离 | 偏离度 | actual/target - 1 |
| G. 对比 | 差异 | max ÷ min |
| H. 行动 | 建议 | 诊断 + 优先级 |

**规则**：至少用5类，每类≥1条，最终≥7条

**输出格式**：
```
🔍 洞察 #N：[方法标签]
- 现象：……
- 数字证据：……
- 方法：……
- 置信度：……
- 建议：……【紧急/重要/长期】
```

## 维度分析数量（写死）

- 单维度：覆盖≥80%核心维度
- 组合维度：3维度以下≥2个，3维度以上≥3个

## 热力图设计（写死）

- X轴：维度数量多的
- Y轴：维度数量少的
- 超出页面：横向滚动

## Tool模式代码健壮性（写死）

1. Sheet名识别：4层兜底（精确→别名→推断→位置）
2. 字段识别：识别不到→填空值或0
3. 数据类型：数值字段转数字，空值转0
4. 公式正确性：分母为0→显示"-"或"0"
5. 错误处理：出错→显示红色提示，不白屏
6. 降级显示：数据为空→"暂无数据"，KPI没数据→0

## Tool模式自检逻辑（写死）

```
1. 总量校验：各分类加总 vs KPI总计（差异>10%→警告）
2. 公式校验：分子分母验证（倒置→错误）
3. 极端值校验：异常值识别（异常→标记）
```

**自检结果展示**：
- 通过 → "✅ 已通过数据自检"
- 警告 → "⚠️ 数据口径不一致"
- 错误 → "❌ 公式错误"
