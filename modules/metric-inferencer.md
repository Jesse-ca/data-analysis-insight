# 指标推断模块

## 执行约束（写死）

1. 只输出规则指定的JSON格式
2. 禁止添加解释性描述
3. 禁止修改输出格式
4. 禁止跳过任何推断步骤
5. 缺任何一项 → 输出错误提示

## 职责

基于场景识别结果，AI自动推断应该计算哪些KPI。

## 核心原则

**让AI自由推断**，不使用预设模板。AI根据数据特征和业务场景，自主判断应该计算哪些KPI。

## AI推断流程

```
1. 接收场景识别结果
   - 数据结构
   - 字段列表
   - 数据规模
   - 行业特征

2. 分析数据特征
   - 有哪些数值字段？（可能是KPI）
   - 有哪些分类字段？（可能是维度）
   - 有哪些ID字段？（可能是关联键）
   - 有哪些日期字段？（可能是时间维度）

3. 推断业务场景
   - 根据字段名推断业务含义
   - 根据数据结构推断分析模式
   - 结合用户描述确认场景

4. 推断KPI
   - 选择核心指标（必须计算）
   - 选择辅助指标（可选计算）
   - 定义计算公式
   - 定义格式和单位

5. 推断分析维度
   - 选择主要维度
   - 选择次要维度
   - 定义维度层次

6. 输出推断结果
```

## 推断原则

### KPI选择原则

| 原则 | 说明 |
|------|------|
| **业务相关性** | 选择与业务场景相关的KPI |
| **数据可得性** | 只选择数据支持的KPI |
| **层次性** | 核心KPI + 辅助KPI |
| **可计算性** | 公式必须能从数据中计算 |

### 公式推断原则

| 原则 | 说明 |
|------|------|
| **原子指标** | 只计算原子指标，不计算汇总指标 |
| **单表计算** | 每个KPI只基于单表计算 |
| **禁止跨表** | 不跨表关联计算 |
| **公式明确** | 公式必须明确，不能有歧义 |

### 维度推断原则

| 原则 | 说明 |
|------|------|
| **字段类型** | 日期类→时间维度，分类类→分组维度 |
| **业务含义** | 根据字段名推断维度含义 |
| **层次结构** | 支持维度下钻（如有层级关系） |

## 推断结果格式

```json
{
  "scene": "AI推断的场景",
  "description": "AI对场景的描述",
  "kpis": [
    {
      "name": "销售额",
      "type": "core",
      "formula": "SUM(金额)",
      "format": "万元",
      "description": "总销售额",
      "dataSource": "订单明细"
    }
  ],
  "dimensions": [
    {
      "name": "时间",
      "fields": ["日期"],
      "granularity": "月"
    }
  ],
  "analysisScope": {
    "timeRange": "2024-01-01 ~ 2024-12-31",
    "mainDimensions": ["时间", "区域"],
    "coreMetrics": ["销售额", "订单数"]
  }
}
```

## 特殊规则

### 原子指标规则

- 只计算原子指标（单表字段）
- 禁止计算汇总指标（跨表关联）
- 每个KPI必须有明确的计算公式

### 公式明确规则

- 公式必须明确，不能有歧义
- 必须说明：分子是什么、分母是什么
- 必须说明：数据来源是哪个表

### 格式规范规则

- 数值必须有单位（元、万元、%等）
- 百分比必须说明是小数还是百分比
- 日期必须说明格式

## 错误处理

- 无法识别KPI → 使用基础KPI（总数、平均值）
- 无法识别维度 → 使用所有分类字段
- 公式不确定 → 标记为"待确认"
- 数据不足 → 跳过该KPI
