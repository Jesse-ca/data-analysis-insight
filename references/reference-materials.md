# 参考材料

## 行业KPI库

### 销售行业

| KPI | 公式 | 说明 |
|-----|------|------|
| 销售额 | SUM(金额) | 总销售额 |
| 订单数 | COUNT(订单) | 总订单数 |
| 客单价 | 销售额/客户数 | 平均每单金额 |
| 达成率 | 实际/目标 | 目标完成率 |
| 退货率 | 退货数/销售数 | 退货比例 |
| 同比增长率 | (本期-去年同期)/去年同期 | 同比增长 |
| 环比增长率 | (本期-上期)/上期 | 环比增长 |

### 进销存行业

| KPI | 公式 | 说明 |
|-----|------|------|
| 库存量 | 当前库存数量 | 当前库存 |
| 周转率 | 出货成本/平均库存 | 库存周转效率 |
| 周转天数 | 365/周转率 | 平均周转天数 |
| 缺货率 | 缺货次数/总需求 | 缺货比例 |
| 安全库存 | 平均日销量×补货周期 | 安全库存量 |

### 保险行业

| KPI | 公式 | 说明 |
|-----|------|------|
| 保费收入 | SUM(保费) | 总保费收入 |
| 赔付率 | (已决+未决+费用-追偿)/保费 | 赔付比例 |
| 费用率 | 费用/保费 | 费用比例 |
| 边际贡献率 | (保费-赔付-费用)/保费 | 边际贡献 |
| 保单数 | COUNT(保单) | 总保单数 |
| 续保率 | 续保数/到期数 | 续保比例 |

### 电商行业

| KPI | 公式 | 说明 |
|-----|------|------|
| 转化率 | 转化数/访客数 | 访客转化比例 |
| 客单价 | 销售额/订单数 | 平均每单金额 |
| 复购率 | 复购客户数/总客户数 | 客户复购比例 |
| GMV | SUM(成交金额) | 总成交金额 |
| UV | COUNT(独立访客) | 独立访客数 |
| PV | COUNT(页面浏览) | 页面浏览量 |

### 制造行业

| KPI | 公式 | 说明 |
|-----|------|------|
| 良品率 | 良品数/总数 | 产品合格率 |
| 产量 | SUM(产出数量) | 总产出 |
| 设备利用率 | 实际运行时间/可用时间 | 设备使用效率 |
| 工时效率 | 有效工时/总工时 | 工时使用效率 |
| 废品率 | 废品数/总数 | 废品比例 |

## 图表设计指南

### 图表类型选择

| 数据特征 | 推荐图表 | 原因 |
|----------|----------|------|
| 时间序列 ≤5点 | 柱状图 | 数据点少，柱状图清晰 |
| 时间序列 6-12点 | 折线图 | 数据点适中，折线图展示趋势 |
| 时间序列 >12点 | 面积图 | 数据点多，面积图展示趋势 |
| 类别对比 ≤5类 | 柱状图 | 类别少，柱状图对比清晰 |
| 类别对比 >5类 | 横向条形图 | 类别多，横向排列易读 |
| 占比分析 ≤6类 | 饼图 | 类别少，饼图展示占比 |
| 占比分析 >6类 | 环形图 | 类别多，环形图更清晰 |
| 2分类+1数值 | 热力图 | 多维交叉分析 |
| 3维度 | 气泡图 | 展示三维关系 |

## 最佳实践

### 1. 数据准备

- 字段命名清晰明确
- 数值字段使用数字格式
- 日期字段使用日期格式
- 分类字段值一致

### 2. KPI设计

- 选择核心KPI（3-5个）
- 公式明确无歧义
- 有对比基准（同比/环比/目标）
- 格式规范（单位、小数位）

### 3. 图表设计

- 选择合适的图表类型
- 遵循视觉层次
- 添加必要的标签
- 确保可读性

### 4. 洞察输出

- 使用Situation-Complication-Resolution结构
- 包含具体数字
- 给出可执行建议
- 标注优先级
